Every candidate, already on file so the letter starts half written

Candidates live in one database in Bolto. Start an offer and their name, email, role, start date, manager and pay come straight from their record, so there’s less to type and every letter says the same thing the rest of Bolto does.

  • Less to write: the details you already know are filled in for you
  • Consistent everywhere: one record, so the letter can’t disagree with payroll
  • Still yours to change: every auto-filled detail stays editable in the letter
